# ELSA-HRS Core Risk Reproducibility Package

This repository is the public-code version of the analysis pipeline for:

Calibrated core-only longitudinal risk prediction of disease and functional transitions in aging cohorts: development in ELSA and cross-cohort replication in HRS.

The package is intentionally not a full project dump. It contains the scripts, templates, and nonrestricted metadata needed to reproduce the paper workflow after obtaining authorized access to the underlying ELSA and HRS data. It excludes raw data, imputed participant-level files, model-ready transition tables, generated figure galleries, manuscript drafts, and local paths.

## Data Access

Raw and derived participant-level ELSA and HRS data are not redistributed here.

ELSA data can be requested through the ELSA data-access process and the UK Data Service:

- https://www.elsa-project.ac.uk/accessing-elsa-data

HRS and RAND HRS data can be requested through the Health and Retirement Study data portal:

- https://hrsdata.isr.umich.edu/

The analyses in the manuscript used the restricted version 3.5.x data releases available to the authors at the time of analysis. Users must obtain the appropriate files from the original data providers and place them locally according to `config/paths_template.yaml`.

## Contents

- `scripts/analysis/`: canonical transition-building, LR/DNN fitting, evaluation, damage/repair, feature-selection, sex-stratified, and manuscript-asset scripts.
- `scripts/visualization/`: figure-generation scripts used for calibration, ER10, target metrics, damage/repair, decision-curve, sex-stratified, and feature-selection displays.
- `scripts/schema/`: ELSA-HRS shared-schema mapping script.
- `metadata/`: nonrestricted schema, target, prevalence, and analysis-freeze metadata.
- `config/`: editable templates for local paths and analysis choices.
- `outputs_manifest/`: lists of manuscript-facing tables and figures generated by the private analysis run.

## Reproduction Order

After installing dependencies and configuring local data paths:

```bash
python scripts/analysis/16_run_analysis_freeze.py --scenario MNAR --method Pmm
```

This orchestrates the ELSA full workflow, ELSA shared-subset workflow, HRS shared-subset workflow, and manuscript asset construction.

Individual components can be run with:

```bash
python scripts/analysis/00_run_paper_pipeline.py --scenario MNAR --method Pmm --include-damage-repair
python scripts/analysis/15_run_elsa_shared_pipeline.py
python scripts/analysis/10_run_hrs_shared_pipeline.py
```

## Public-Repository Boundary

Included:

- Analysis source code.
- Configuration templates.
- Nonrestricted variable mappings and target definitions.
- Output manifests.
- Environment requirements.

Excluded:

- Raw ELSA `.sav` or HRS/RAND files.
- Imputed wave-level participant files.
- Model-ready transition tables.
- Participant-level sex lookup files.
- Generated probability files, metrics directories, figures, and manuscript drafts.

## Citation

If you use this code, please cite the manuscript and the original ELSA and HRS data sources according to their data-use agreements.
