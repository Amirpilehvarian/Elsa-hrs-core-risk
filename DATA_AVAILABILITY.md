# Data Availability

This repository does not redistribute raw or derived participant-level ELSA or HRS data.

ELSA data are available by request through the ELSA data-access process and the UK Data Service:

- https://www.elsa-project.ac.uk/accessing-elsa-data

HRS and RAND HRS data are available by request through the Health and Retirement Study data portal:

- https://hrsdata.isr.umich.edu/

The analyses reported in the manuscript used project-local restricted inputs documented in the analysis-freeze record: preserved `MNAR_Pmm` imputed ELSA core wave tables covering ELSA waves 1-9, and a supplied preprocessed RAND/HRS Markov-format table covering HRS waves 6-15 (2002-2020). Reproducing users must obtain authorized local copies from the original data providers and configure local paths using `config/paths_template.yaml`.
